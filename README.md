# ⚔️ AnimeHUB | Dream — Навигация по «Бличу»

Версия проекта Dragon Ball, переделанная для канала «Блич». Работает через **Bot API**, поэтому `TELEGRAM_API_ID`, `TELEGRAM_API_HASH` и `SESSION_STRING` не требуются.

## Что будет в меню

- **⚔️ Блич (оригинальный сериал)** — 10 опубликованных сюжетных арок, прямые кнопки на твои посты.
- **🔥 Тысячелетняя кровавая война** — 4 публикации: Amber и DEEP для начала, «Прощание» и «Конфликт».
- **📢 Канал «Блич»** — пригласительная ссылка `https://t.me/+gnBXocT0HL40YTRi`.

Все 14 ссылок из твоего сообщения уже записаны в `catalog.json`. Не опубликованные в твоём списке филлерные арки **не добавлены**, ссылки не выдуманы.

**Исправление по сравнению с Dragon Ball:** кнопки главного меню в канале открывают **личный чат с ботом**. Поэтому нажатие одного зрителя не изменит меню для всех в канале.

## Установка на BotHost

1. Создай **отдельного** Telegram-бота в `@BotFather` или отключи прежний процесс, если хочешь использовать его токен. **Не запускай два polling-приложения одновременно на одном BOT_TOKEN.**
2. Создай репозиторий на GitHub и загрузи **содержимое этой папки** (не ZIP-файл целиком). В корне должны быть `main.py`, `catalog.json`, `requirements.txt`.
3. В BotHost выбери платформу Telegram, язык Python, Python 3.11, Git URL репозитория, ветку `main`, главный файл `main.py`.
4. Поле Bot Token заполни токеном нового бота. **Не присылай его никому и не добавляй в публичный репозиторий**.
5. Добавь переменную `OWNER_USER_ID` со своим Telegram ID (можно сначала запустить бота и отправить `/myid`, затем добавить переменную и перезапустить).
6. Добавь переменную `BLEACH_CHANNEL_ID` со значением `-1003593534577`. Это ID, выведенный из ссылок `t.me/c/3593534577/...` — **перед публикацией обязательно проверь реальное название канала через `/status`**.
7. Добавь бота в канал «Блич» администратором с правами **публикации**, **редактирования** и **закрепления** сообщений.
8. Пересобери и перезапусти BotHost.

## Проверка команд в личном чате бота

| Команда | Для чего |
| --- | --- |
| `/start`, `/bleach` | Главное меню |
| `/myid` | Твой Telegram ID |
| `/status` | Текущий канал и права |
| `/set_channel -1003593534577` | Привязать канал после проверки |
| `/preview` | Предпросмотр без публикации |
| `/post_nav` | Подготовить публикацию и показать название канала |
| `/confirm_nav` | Подтвердить отправку в канал |
| `/cancel_nav` | Отменить подготовленную публикацию |
| `/pin_nav` | Закрепить последний пост навигации |
| `/set_nav 123` | Восстановить ID уже опубликованного этим ботом сообщения |
| `/update_nav` | Обновить опубликованное меню без создания ещё одного поста |
| `/links` | Все ID арок и ссылки |
| `/setlink substitute https://t.me/c/3593534577/23` | Изменить ссылку на арку |

**Порядок первого запуска:** `/start` → `/status` → `/preview` → `/post_nav` → `/confirm_nav` → `/pin_nav`.

## Где менять список арок

Редактируй файл **`catalog.json`**, поле `sections[].items[]`: `id`, `name`, `episodes`, `url`. Для новых частей/арок просто добавь объект в нужный раздел. После обновления GitHub пересобери проект на BotHost.

`/setlink` позволяет временно менять ссылки из Telegram, но BotHost может очищать `state.json` при пересборке. **Все постоянные изменения дублируй в `catalog.json`**. Аналогично `last_nav_message_id` может быть потерян после пересборки; для более надёжного хранения понадобится внешняя БД или постоянный том. Можно вручную восстановить ID поста командой `/set_nav 123`, если ранее опубликованное меню существует.

## Важная особенность нумерации

Для совпадения с уже опубликованными сообщениями в `catalog.json` оставлены диапазоны, которые ты прислал: **366–379** для первого этапа TYBW и **393–405** для «Конфликта». При *сквозной* нумерации оригинальных 366 серий плюс продолжение это обычно **367–379** и **393–406**. Если хочешь официальную сквозную нумерацию, исправь два значения `episodes` в `catalog.json` — на сами ссылки это не повлияет.

## Безопасность

Пользоваться меню могут подписчики. **Публиковать, закреплять, менять канал и ссылки может только `OWNER_USER_ID` в личных сообщениях с ботом.** Если владелец не задан, эти команды заблокированы.

Не добавляй в GitHub `.env`, `state.json`, токены, Telegram-сессии или любые пароли. Код не требует Premium-авторизации.
